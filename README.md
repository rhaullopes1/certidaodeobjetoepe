# Certidão de objeto e pé

Crie um site completo, moderno e altamente profissional para uma empresa especializada em solicitação de Certidão de Objeto e Pé em todo o Brasil.



O objetivo principal do site é gerar pedidos pelo WhatsApp e formulário, transmitindo confiança, autoridade, segurança e facilidade para pessoas que precisam obter uma certidão judicial sem entender os procedimentos dos tribunais.



Objetivo do projeto



Criar uma landing page de alta conversão com foco em:



Captar leads qualificados;

Converter visitantes em solicitações;

Explicar o serviço de forma simples;

Passar credibilidade jurídica;

Facilitar o contato imediato pelo WhatsApp.
